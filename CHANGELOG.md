# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Changed

- View of the value now updates right after a change
- Name and description of the value/metric is now duplicated in the editing panel
- One can now delete saved values

### Fixed

- Problems with loading physical values
- Incorrect warning generation
- Incorrect mood episode detection
- Old list of scale value categories
- Error while entering current week
- Borderline values weren't visible on plots
- Cleaned up code and tests

## [1.0.0-beta.1] - 2026-08-15

### Added

- Project & license information
- Discrete scale values and continuous physical values: log your state
- Plotting and statistical analysis for values
- Warnings: know when your values are off
- Alarms: important notifications based on your logging
- Default values, warnings, and alarms: track mood, anxiety, BPD symptoms, quality of life, and lithium levels
